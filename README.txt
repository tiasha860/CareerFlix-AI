CareerFlix AI - Thonny setup

1. Extract this ZIP into one folder.
2. Open the folder's app.py in Thonny.
3. Install dependencies if needed: flask, pypdf, sentence-transformers, scikit-learn.
4. Click Run.
5. Open http://127.0.0.1:5001/interview for interview practice.

Interview Practice now generates an ongoing stream of open-ended questions.
It includes concept explanations, comparisons, coding tasks, debugging,
complexity analysis and scenarios. Data Structures has dedicated DSA prompts.
The answer review is a basic checklist; it is not an AI correctness score.


NEW PRACTICE TRACKING
- On Interview, write an answer and click Review My Answer.
- CareerFlix saves the question, topic, answer, word count and improvement tips in this browser.
- Open Progress to see your saved answers, topics practised and word count.
- Data is stored in browser localStorage, not in a cloud account or shared between browsers/devices.
- The review provides structure/writing suggestions; it does not verify technical correctness or give an AI score.
- Clearing browser site data can erase this practice history.
